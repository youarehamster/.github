# You Are Hamster 🐹

A tiny home for **This Role: You are Hamster**, the short comedy horror game created by [SeenThai](https://seenthai.itch.io/this-role-you-are-hamster).

### [Play and explore at YouAreHamster.com →](https://youarehamster.com/)

On the site, you can open the browser game window, see images from the original game page, watch two gameplay videos, learn the listed controls, and read quick answers before you play.

**New to the game?** Start with the [play window and controls](https://youarehamster.com/#play). For the creator’s original release and updates, visit [SeenThai on itch.io](https://seenthai.itch.io/this-role-you-are-hamster).

YouAreHamster.com is an independent page about the game. The original game and characters belong to SeenThai.
